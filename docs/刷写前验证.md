## 已完成的验证

- 动平衡工具启动页和主仪表页面可正常加载。
- 设置、标定、记录、诊断和 OTA 控件保留。
- ESP32-C3 应用镜像结构和校验值已通过 `esptool image-info` 检查。
- macOS 可识别 ESP32-C3 USB-Serial/JTAG 下载端口。
- 本仓库不包含原始固件、设备 NVS 或设备专属识别信息。

## 刷写地址

只有在确认设备进入下载模式、并已保存原始备份后再执行写入：

```text
bootloader  0x0000
partition   0x8000
nvs          0x9000
otadata      0xe000
app0        0x10000
```

不要把 `app0-ui.bin` 当作从 `0x0000` 开始的整片固件。完整镜像和应用分区的写法取决于设备当前的升级方式，刷写前应先确认厂商升级流程。
