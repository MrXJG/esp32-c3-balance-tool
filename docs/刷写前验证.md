## 刷写地址

只有在确认设备进入下载模式、并已保存原始备份后再执行写入：

```text
bootloader  0x0000
partition   0x8000
nvs          0x9000
otadata      0xe000
app0        0x10000
```

不要把 `app0-ui-nobrand.bin` 当作从 `0x0000` 开始的整片固件。完整镜像和应用分区的写法取决于设备当前的升级方式，刷写前应先确认厂商升级流程。
